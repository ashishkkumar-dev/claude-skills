# Changelog: response-formats

## 0.1.0

First version.

- 7 template families: Answer, Explain, Fix, Investigate, Make, Co-design, Coach. Personal messages get prose.
- Intent is classified for each message, with 8 ordered questions, so each message gets exactly one family.
- Context rules: current object, already covered, depth signal.
- Object rules: revise, do not rebuild; place, do not append; keep the object current; one definition for each term.
- Global rules: ASD-STE100, terms rule, no repeats, 150 words for a simple question.
